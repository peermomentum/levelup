# Buddy Partnership Suggestion Email Template

Use when Success Circles wants to suggest two members as a Momentum Buddy pairing and send/draft the message from `connect@successcircles.com`.

## Rules

- Audience is the two proposed buddies, unless the user explicitly names a third-party recipient.
- Use process-oriented language; do **not** use “hustle.” Preferred phrase: “the process of owning and operating a business.”
- Pull each member’s current Airtable background before drafting: availability, focus areas, occupation/vocation, personality/profile notes, and any caution notes.
- If either person is marked unavailable, mention that availability should be confirmed before proceeding.
- If the user asks to draft from `connect@successcircles.com`, create a Gmail draft only and report draft ID/message ID; do not send without explicit approval.
